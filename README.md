# arXiv Paper Classification Service

A Django REST API that classifies research articles into arXiv categories using BERT-based adapter models. The pipeline runs in two stages: parent category classification followed by subcategory classification.

## Prerequisites

- Python 3.10+
- Anaconda (recommended)
- Trained adapter weights in the `resources/` folder (not tracked by git)

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure environment variables

Copy the example below into a `.env` file at the project root:

```env
SECRET_KEY=django-insecure-change-me-in-production
DEBUG=True
LOG_DIR=./logs
CACHE_THRESHOLD=0.95
MODEL_NAME=allenai/specter2_base
CACHE_EMBEDDING_MODEL=all-MiniLM-L6-v2
```

| Variable | Description | Default |
|---|---|---|
| `SECRET_KEY` | Django secret key | — |
| `DEBUG` | Enable Django debug mode | `True` |
| `LOG_DIR` | Directory for log files | `./logs` |
| `CACHE_THRESHOLD` | Cosine similarity threshold for the semantic cache (0–1) | `0.95` |
| `MODEL_NAME` | Base BERT model name | `allenai/specter2_base` |
| `CACHE_EMBEDDING_MODEL` | Sentence-transformers model used for cache embeddings | `all-MiniLM-L6-v2` |

### 3. Verify resource files

The `resources/` folder must contain the trained adapters and config files:

```
resources/
  parent_categories_adapter/
  parent_categories_adapter_bucket2/
  parent_categories_adapter_bucket3/
  Computer Science_categories_adapter/
  Economics_categories_adapter/
  ...  (one adapter folder per parent category)
  target_sub_classes.json
  categories_hierarchy.json
```

These are generated by the training notebooks and are not included in the repository.

## Running the server

```bash
python src/web/manage.py runserver
```

The server starts at `http://127.0.0.1:8000/`. On first request the ML models are loaded lazily, so the initial prediction may take longer.

## API Endpoints

### Create a classification task

```
POST /api/tasks/
Content-Type: application/json
```

**Request body:**

```json
{
  "items": [
    {
      "title": "Attention Is All You Need",
      "abstract": "The dominant sequence transduction models are based on complex recurrent or convolutional neural networks..."
    }
  ]
}
```

**Response (201):**

```json
{
  "task_id": "b3f1a2c4-..."
}
```

### Get task status / result

```
GET /api/tasks/<task_id>/
```

**Response (200):**

```json
{
  "task_id": "b3f1a2c4-...",
  "status": "FINISHED",
  "result": [
    {
      "parent_categories": ["Computer Science"],
      "labels": ["cs.CL", "cs.LG"]
    }
  ]
}
```

Status values: `NOT_STARTED`, `IN_PROGRESS`, `FINISHED`. The `result` field is only present when status is `FINISHED`.

### Get queue status

```
GET /api/queue/
```

**Response (200):**

```json
{
  "queue": [
    { "task_id": "...", "position": 1, "status": "IN_PROGRESS" },
    { "task_id": "...", "position": 2, "status": "NOT_STARTED" }
  ]
}
```

## Logs

Logs are written to `LOG_DIR/service.log` (default: `./logs/service.log`) and also printed to the console. The log directory is created automatically on startup.
